# Proyecto de ejemplo VULNERABLE

Tienda de mentira con errores de seguridad plantados a propósito, uno por cada
categoría que revisa la skill. Mezcla Express, Next.js, FastAPI, Supabase y
Firebase para cubrir todo en un solo proyecto. No es código para usar.

Las claves son marcadores `@@...@@`: `pruebas/revisor-seguridad/construir.py`
los cambia por valores falsos al armar el proyecto en una carpeta temporal,
para no subir nada con formato de clave real a GitHub.
